# 🍕 Pizza Bank POS

A professional Point of Sale system for Pizza Bank Hotel.

## Features
- Full menu with 20+ items across 6 categories
- Live cart with qty controls
- Dine-in / Takeaway / Delivery modes
- Table management (T1–T8)
- Discount % + 5% tax calculation
- KOT (Kitchen Order Ticket)
- Cash / Card / Split / Hold payments

## Deploy on Vercel

1. Push this folder to a GitHub repo
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your GitHub repo
4. Click **Deploy** — done!

## Local Test

Just open `index.html` in any browser. No build step needed.
